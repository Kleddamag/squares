# Lazy First-Leg Enclosures

Registered after exp-009, from its failure.
Lemma R7’s path bound with the $x$ leg first is $F(p_0) - G^S_x d_x - G_y d_y$; it can
clear the threshold only if the margin $F(p_0) - T$ is at least $G_y d_y$. So compute
$G^S_x$ only when the box bound fails and that necessary condition holds, and likewise
$G^S_y$ with $G_x d_x$. The accepted boxes are exactly H-004’s, so the node count should
be H-004’s; the extra enclosures are paid only at the boxes that might use them.

Prediction: H-004’s node counts, and at least 10% fewer search instructions than c2.
