# `s(77)` — open

**External intake, 2026-10-01.** wand125’s
[rectangle-density source](../resources/web/wand125-rectangle-certificates-2026-10-01/README.md)
reports a direct $3573/400 = 8.9325$ certificate for this case, with total mass
$7699/100 = 76.99 < 77$, accepted by Tokoharu’s unchanged interval checker.
The replayed n75 certificate carries `s(77) >= 889/100 = 8.89` here by monotonicity,
which is the verified lower bound.

direction.

Open. The best known packing gives $s(77) \le 9$, and the verified lower bound is

## The packing

The record catalogue does not picture $n = 77$: no arrangement has ever been found that
beats the trivial $\lceil\sqrt{77}\rceil = 9$ grid, so the grid is still the best known
packing. That is a statement about what has been searched, not a proof.

## The lower bound

Nagamochi’s general closed form, the verified lower bound before this certificate,
applies to every $N \ge 4$:

```
s(N) ≥ min{ ⌈√N⌉,  √(N − 2⌊√N⌋ + 1) + 1 }
```

See the [Frontier corpus summary](README.md#what-the-corpus-shows) for the current
aggregate count; source-reported bounds are recorded separately.
