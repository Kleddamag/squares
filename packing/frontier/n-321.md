# `s(321)` — open

**External intake, 2026-10-01.** Evan Daniel’s
[source](../resources/web/evand-square-packing-2026-10-01/README.md) reports
$s(321) = 18$ as the case $k = 18$ of $s(k^2 - 3) = k$ for every integer $k \ge 6$
(T-064). By the source’s report, its Lean development derives the family from one finite
covering statement, `Valid7`, which a single exact Python checker at the source decides.
Neither has been run here, so the verified lower bound is unchanged and the case stays
open. The source’s `CREDITS.md` says the work was produced by Claude (Anthropic) in a
single session under human direction.

Open. The best known packing gives $s(321) \le 18$, and the strongest lower bound
independently verified here is $17.970562$ from Nagamochi’s general theorem, leaving a
gap of $0.0294$. General closed form: s(N) >= min(ceil(sqrt(N)), sqrt(N -
2*floor(sqrt(N)) + 1) + 1).

## The packing

The record catalogue does not picture $n = 321$: no arrangement has ever been found that
beats the trivial $\lceil\sqrt{321}\rceil = 18$ grid, so the grid is still the best
known packing. That is a statement about what has been searched, not a proof.

## The lower bound

The strongest lower bound independently verified in this record is Nagamochi’s general
closed form, which applies to every $N \ge 4$:

```
s(N) ≥ min{ ⌈√N⌉,  √(N − 2⌊√N⌋ + 1) + 1 }
```

Source-reported bounds are recorded separately from this independently verified theorem.
