# `s(193)` — open

**External intake, 2026-10-01.** The pinned Evan Daniel source reports `s(193) = 14` as
an instance of `s(k² − 3) = k` at `k = 14` (T-064). Lean proves the general reduction
conditional on `Valid7`; the exact Python checker for that premise has not been freshly
replayed here, so the verified case remains open.
The source’s CREDITS.md says this work was produced by Claude (Anthropic) in a single
session under human direction.

Open. The best known packing gives `s(193) ≤ 14`, and the strongest lower bound
independently verified here is `13.961481` from Nagamochi’s general theorem, leaving a
gap of `0.0385`. General closed form: s(N) >= min(ceil(sqrt(N)), sqrt(N -
2*floor(sqrt(N)) + 1) + 1).

## The packing

The record catalogue does not picture `n = 193`: no arrangement has ever been found that
beats the trivial `⌈√193⌉ = 14` grid, so the grid is still the best known packing.
That is a statement about what has been searched, not a proof.

## The lower bound

The strongest lower bound independently verified in this record is Nagamochi’s general
closed form, which applies to every `N ≥ 4`:

```
s(N) ≥ min{ ⌈√N⌉,  √(N − 2⌊√N⌋ + 1) + 1 }
```

Source-reported bounds are recorded separately from this independently verified theorem.
