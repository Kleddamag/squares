Here are some of the problem-solving tools I've built, grouped by area, in case any are useful to others. Most aren't public yet; I plan to clean them up and publish them.

1. Moving certificates between n and L (on top of tokoharu's rectangle-density solver)
- Expanding n: a certified certificate for n can seed a larger n. Weights are re-optimized, so the new proof is independent of the parent.
- Climbing L: when the LP hits the mass budget, a budget-recovery step prices new rectangles along the four edges and climbs L in small steps (0.01 or less).
- Rescaling: a candidate can be shrunk or enlarged exactly to a nearby L, then fitted back to the budget.
- Inheritance by mass: one certificate also gives bounds for larger n when its total mass is below them.
- A ceiling: with core side B, no certificate can reach L ≥ B·UB(n), because the known packing shrunk by B then fits n disjoint cores. We cap targets there, which saves a lot of wasted runs near integer upper bounds.

2. Speeding up the solver
- Counterexample screening runs in parallel over the angle net (about 3–4x faster).
- Counterexamples are fed back to the LP in batches of 16, prioritizing recent directions.
- LP state is reused between rounds (40–50% less solve time in our comparisons).
- A lower-memory "working" LP is used for long continuations.
- An axis-direction cache speeds up in-job checks. Published certificates are always replayed with the unmodified verifier.

3. Verification and publication
- Before publishing, every certificate is replayed on all 201 angle cases with tokoharu's unmodified verify.cpp, with the verifier and file hashes pinned, several replays in parallel.
- Certificates that fall outside that format (like our n = 50 ones, which reach coverage ≥ 1 but not 1.0001) ship with their own verifier and a full replay bundle.

4. Formalization
- A Lean 4 overlay on top of evand's unmodified Lean files: a script turns a certificate into a Lean data file, and the reduction to minSide n = k is proved from a single capture hypothesis (used for our point-only s(21) = 5).

5. Point-certificate checking
- A faster variant of evand's zmx2 that computes line intersections lazily, regenerated from a fixed patch and compared region by region against the original.

6. Records and visualization
- A lower-bound table for n ≤ 100 with sources, including values inherited from smaller n.
- A browser viewer that draws the rectangles of each published certificate.

7. Running it all
- Jobs run on local machines plus GCP Spot instances with memory-aware scheduling.
- A 30-minute monitoring loop continues, advances, retries or moves each ladder automatically, and restarts from saved state after a machine is preempted.
